Inference for Regression Analysis

Confidence Interval:

bj ∓ t 1−α/2,n−p−1 s bj

Hypothesis Testing:

T.S. = bj−βj0 sβj ∼H0 tn−p−1

Where (for simple linear regression only):

sβ1 = s ∑ i=1 n (xi − x_ ) 2

CI on mean response (for simple linear regression only):

y^ ∓ t 1−α/2,n−2 ( s 1n + (xobs−x_) 2 ∑ j=1 n (xj−x_) 2 )

PI on response (for simple linear regression only):

y^ ∓ t 1−α/2,n−2 ( s 1 + 1n + (xnew−x_) 2 ∑ j=1 n (xj−x_) 2 )

Simultaneous inference:

T.S. = SSEred−SSEfull dfEred−dfEfull SSEfull dfEfull ∼H0 F ν1,ν2

Where:

ν1 = dfEred − dfEfull ν2 = dfEfull

CRD Model

Yij = μ+αi = μi + ϵij ϵij ∼i.i.d. N (0,σ2)

CRD Sums of Squares

SST=SSE+SSTrt (N−1) = (N−t) + (t−1) SST= ∑ i=1 t ∑ j=1 ni ( yij − y_++ ) 2 SSE= ∑ i=1 t ∑ j=1 ni ( yij − y_i+ ) 2 SSTrt= ∑ i=1 t ∑ j=1 ni ( y_i+ − y_++ ) 2

CRD Inference

T.S. = MSTrtMSE ∼H0 Ft−1,N−t

RBD Model

Yij = μ+ αi + βj + ϵij ϵij ∼i.i.d. N (0,σ2)

RBD Sum of Squares

SST=SSE+SSTrt+SSBlock (bt−1) = (b−1) (t−1) + (t−1) + (b−1) SST= ∑ i=1 t ∑ j=1 b ( yij − y_++ ) 2 SSTrt= ∑ i=1 t b ( y_i+ − y_++ ) 2 SSBlock= ∑ j=1 b t ( y_+j − y_++ ) 2 SSE= ∑ i=1 t ∑ j=1 b ( yij − y_i+ − y_+j + y_++ ) 2

RBD Inference

T.S. = MSTrtMSE ∼H0 F t−1, (b−1) (t−1)
